# T_NATURAL_EVENTS — Natural and exceptional events (Art. 16 — Directive)

Defines types and conditions of natural/exceptional events for exclusion from compliance.

| Event Type | Examples | Required Evidence |
|---------------------|------------------------------------|--------------------|
| Natural source | Saharan dust, wildfires, sea salt | meteorological/scientific documentation |
| Exceptional event | winter road sanding | intervention records, technical notes |
| Volume threshold | attributable concentration | source analysis + environmental data |

---

## Exclusion criteria

- exceedances recognized as excluded from compliance calculation
- objective documentation must exist
- see `M_LIMITS`
