# T_NATURAL_EVENTS - Eventi naturali ed eccezionali (Art.16 — Directive)

Definisce tipi e condizioni di eventi naturali / eccezionali per esclusione da compliance.

| Event Type          | Examples                           | Required Evidence |
|---------------------|------------------------------------|--------------------|
| Natural source       | polveri sahariane, incendi boschivi, sale marino | documentazione meteo/scientifica |
| Exceptional event    | sabbiatura invernale stradale      | registrazioni di interventi, note tecniche |
| Volume threshold     | concentrazione attribuibile        | analisi fonte + dati ambientali |

---

## Cause di esclusione

- superamenti riconosciuti come esclusi dal calcolo di conformità
- deve esistere una **documentazione oggettiva**
- vedi `M_LIMITS`
